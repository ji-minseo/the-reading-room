# The Reading Room

An immersive, tactile tarot experience built on the same 78-card rule engine as Pick a Card.

## Direction
- quiet editorial 3D / 2.5D card interaction
- warm ivory paper, burgundy ink, restrained gold
- no AI API at runtime
- 78-card upright/reversed deck, no duplicate picks
- 12 reading types from Pick a Card
- questions remain in the browser

Open `index.html` through a static server or deploy the repository directly to Cloudflare Pages / GitHub Pages.

The Reading Room is a sister experience to Pick a Card: the reading system stays familiar, while choosing and revealing cards becomes the main interaction.
